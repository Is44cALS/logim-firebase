# Correio do Amor

Este projeto é uma aplicação web chamada "Correio do Amor", que permite aos usuários enviar mensagens de amor e participar de um chat em tempo real. A aplicação utiliza Firebase para autenticação e WebSockets para comunicação em tempo real.

## Funcionalidades

- **Autenticação com Google**: Os usuários podem fazer login usando suas contas do Google.
- **Chat em Tempo Real**: Os usuários podem participar de um chat em tempo real.

## Tecnologias Utilizadas

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, WebSocket
- **Autenticação**: Firebase Authentication
- **Hospedagem**: Render
